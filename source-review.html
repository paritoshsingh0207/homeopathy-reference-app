What this page is for

See which source was referred, which medicine identity was extracted, and whether that extraction is confidently understood, doubtful, or not understood. The review data is generated from the same audited SQLite release used by the application.

Medical-review rule: decisions made here are stored only in this browser. They never alter the database automatically. Export the decisions after professional review; approved changes must still go through the versioned source/provenance rebuild and release gates.

Complete

Confidently resolved to a canonical medicine with source-backed evidence. This means the identity mapping is understood; it does not claim that every sentence in the source is extracted.

Doubtful

Ambiguous abbreviation, low-confidence identity, or a mapping accepted only through fuzzy OCR. Medical review is recommended before changing canonical data.

Did not understand

A medicine-like source token could not be mapped safely. The raw text is preserved for manual identification.

Excluded

Noise or non-remedy text retained for audit. It should not be promoted merely to increase the medicine count.
